# RoLauncher icon

The owner selected A, Launch arrow. `RoLauncher.png` is the transparent generated original; `RoLauncher.ico` contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel sizes and is used in the Rust executable, WinUI window, tray and installer.

Three concepts were generated using the built-in image generation tool: A launch arrow, B orbit and C RL monogram. Originals are retained in icon-concepts. Prompt direction: create a distinctive minimal monochrome Windows app icon for RoLauncher, clear at small taskbar sizes, on a transparent background; use a bold launch arrow, an orbital mark, or a compact RL monogram respectively. No full wordmark or Roblox trademark mark. The selected PNG was converted to ICO with Pillow without changing the artwork.
