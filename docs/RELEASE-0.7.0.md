# RoLauncher 0.7.0

Action feedback, including the Discord Send test confirmation, now appears as a compact toast at the top center of the window. It disappears automatically after five seconds and has a close button for early dismissal. A new action gets a fresh timeout. Repeated background failures and unchanged connectivity warnings do not keep reopening or extending the toast. Page content keeps its position when a toast appears or disappears.

The Windows release includes the complete self-contained desktop, WebView2Loader.dll, license notices and AGENTS.md, with corresponding source and SHA256 checksums. Extract the entire ZIP and run RoLauncher.exe.
