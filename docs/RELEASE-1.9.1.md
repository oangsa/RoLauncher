# RoLauncher 1.9.1

Released November 10, 2026.

On Windows, Close can follow a verified handoff from the game to a Roblox Home or tray process. Auto Rejoin waits for cleanup before starting the next game. With Auto Rejoin off, the account stops after cleanup.

If ownership remains unclear, the account shows Needs attention and continues checking for the client. Other accounts can keep playing.

Cleanup checks run more frequently during handoff, and connected games release their launch deadline. Verified Home clients close promptly, with the first clean rejoin ready after confirmed exit.
