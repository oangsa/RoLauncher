# RoLauncher 1.1.0

Linux/Sober beta; `beta-v1.1.0` did not replace stable Windows 1.0.0.

- Uno/Skia shares Windows layouts/controls; Windows keeps native WinUI.
- Linux targets Ubuntu/Arch, GNOME/KDE, X11/XWayland.
- Adds per-account Sober homes, verified clients/logs, Secret Service encryption, WebKit sign-in, portals, tray, checked archive updates.
- Uses installed launch protocol/process details/logs; no Roblox RAM reads or client-file changes.
- Matching look/controls and live recovery unverified; credentials/backups require same OS/user.

## Install the Linux beta

1. Get `rolauncher-v1.1.0-linux-x64.tar.gz` and `rolauncher-v1.1.0-SHA256SUMS.txt`; verify archive entry.
2. Ubuntu 24.04+/current Arch x64: install Sober/dependencies; unlock Secret Service.
3. Extract to stable writable folder; enter `rolauncher-v1.1.0`; run `./RoLauncher`.
4. Sign in again; optionally run `python3 install-linux.py`. .NET is included.

Windows keeps WinUI. Packages include source, AGENTS.md, notices, checksums; published 1.0.0 files unchanged.
Report distro/desktop/session/failed action; never cookies, tickets, launch URLs, raw logs.
