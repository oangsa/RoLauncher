# RoLauncher 1.2.1

- Center update-banner **Download**, **Cancel download**, and **Relaunch** buttons on Windows/Linux.
- The Windows UI fixture measured all three states; Rust, desktop, installer, package, and Linux checks gate publication.

Upgrade through **Check updates → Download → Relaunch**; accounts/settings are retained and backed up.

Packages: `rolauncher-v1.2.1-setup-x64.exe`, `rolauncher-v1.2.1-windows-x64.zip`, and `rolauncher-v1.2.1-linux-x64.tar.gz`.
Source: `rolauncher-v1.2.1-source.zip`; checksums: `rolauncher-v1.2.1-SHA256SUMS.txt`.
Packages include AGENTS.md/notices; prior artifacts stay unchanged.

[Linux remains a preview](https://github.com/oangsa/RoLauncher/blob/v1.2.1/docs/LINUX.md).
