# RoLauncher 1.0.0

First public installer release · 2026-10-06 · Windows x64

- RoLauncher name/icon, per-user installer, shortcuts, uninstall, portable ZIP.
- **Download → Relaunch** backs up data; Roblox stays open.
- Account groups, presets, bulk edits, recovery Dashboard, fallback choices, history.
- Encrypted backups; CI-built portable/source ZIPs, licenses, SHA256 checksums.
- Keep legacy RbxTools accounts/backups; prefer new account data, not update cache.
- Uninstall retains data. Installer is unsigned.

Live recovery, Discord delivery, resource use unverified.
