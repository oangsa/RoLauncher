1.0.0 — RoLauncher: saved sessions and dependable recovery

• Renamed to RoLauncher, including the desktop, tray, notifications, exports and release packages. Existing saved accounts and encrypted backups remain supported.
• Edit selected or all accounts together: aliases/patterns, destinations, rejoin, groups and fallback. Unchecked fields stay unchanged; all changes save atomically.
• Organize accounts into groups and save launch profiles with individual account settings. Review, apply, launch, replace, rename, import and export profiles.
• Recovery dashboard with reasons, countdowns, eligible Retry now and account-specific sign-in repair.
• Destination fallback policy: allow public, stay on destination, or pause and notify.
• Persistent bounded history, account filtering and sanitized support-report export.
• Ten encrypted local backups, pre-upgrade protection, stopped-account restore and offline corruption recovery.
• Launch-arrow app/tray icon and a per-user Windows executable installer with shortcuts and uninstall support.

• Automatic official-GitHub update checks at startup and every six hours. Download verifies SHA256; Relaunch backs up data, installs and reopens automatically. Roblox clients stay open.

• Reviewed feature → dev → main delivery, Windows CI and versioned GitHub releases with complete source, notices and checksums.
• Live multi-account Roblox, recovery and Discord delivery remain unverified; see docs/VALIDATION.md.
